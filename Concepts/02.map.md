my_list = [5, 7, 8]

def doubler(x):
    return 2 * x

output = list(map(doubler, my_list))

The map() function applies the doubler function to each element of my_list.
It returns a map object (iterator), so we wrap it with list() to convert the result into a list.

✅ Clear One-Liner (Interview Style)

map() applies a function to every element of an iterable, and list() is used to convert the resulting iterator into a list.

✅ Step-by-Step Explanation
map(doubler, my_list):
Takes each element from my_list
Applies doubler(x) → multiplies by 2
Returns: an iterator, not a list
list(...):
Converts the iterator into a list

👉 Final output:

[10, 14, 16]
✅ Even Better (Pythonic Insight)

You can also mention:

output = [2 * x for x in my_list]

This is a list comprehension, often preferred in Python for readability.



Later,
output = list(map(lambda x : 2*x, my_list))
